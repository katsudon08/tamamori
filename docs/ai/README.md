# docs/ai

AI との議論・調査・実装計画の一時保管場所。個人用の作業メモを置く。

## 1. 位置づけ

- 思考の途中経過・調査ログ・実装計画のドラフトなどを自由に置く場所。
- 個人用であり、チーム間で共有しない（人によって中身は異なってよい）。

## 2. Git 管理しない

- このディレクトリ内のファイルは原則 Git 管理しない（`.gitignore` で除外）。
- 例外はこの `README.md` のみ。運用ルールを共有するため追跡する。

## 3. チームへの共有（昇格先）

作業メモのうちチームに共有すべき内容は、メモのまま放置せず以下のいずれかに昇格させる。

| 内容 | 昇格先 |
|---|---|
| アーキテクチャ上の判断 | `docs/adr/` |
| 実装単位の説明 | PR 本文 |
| タスク単位の補足 | Issue コメント |
| AI に継続的に守らせるルール | `CLAUDE.md` / `AGENTS.md` |

## 4. ファイル命名規則

`<issue-number>-<title>.md` の形式とする。

- `<issue-number>` … 対応する Issue 番号。
- `<title>` … 内容を表す短い名前をケバブケースで記述する。
- 対応する Issue が無い場合は `<issue-number>-` プレフィックスを省略し、`<title>.md` とする。

例:

- `42-bonsai-growth-phases.md` … Issue #42 に関する議論メモ
- `polling-vs-websocket.md` … 対応する Issue が無い調査メモ
